# Source Bibliography and Router

## 1. Purpose

This file records the source base used to build Version 2.0 of the corpus.

It is a **source router**, not a claim that every source has equal evidentiary weight. The governing evidence rules remain in `00_CORPUS_CONSTITUTION_EVIDENCE_HIERARCHY_AND_SOURCE_ROUTER.md`.

The nine master files are authored syntheses. The underlying books, articles, PDFs, and EPUBs are **not included in this GitHub package**.

## 2. Source-role key

| Role | Meaning |
|---|---|
| **ANCHOR** | Shapes the corpus architecture, evidence rules, or main formulation model |
| **CORE** | Makes a distinctive substantive contribution and is reconstructed in depth |
| **REFERENCE** | Broad source used selectively for coverage and triangulation |
| **BRIDGE** | Connects this corpus to a specialist theoretical tradition |
| **CONTEXT** | Background or historical material used selectively |
| **LINEAGE** | Important mainly for showing how a later construct or evidence base developed |
| **ARCHIVE** | Retained in the research library but not materially reconstructed in Version 2.0 |

## 4. Companion specialist corpuses

These are **deep-reference destinations**, not material to merge into this corpus.

| Companion corpus | Use |
|---|---|
| **Jungian Research Corpus** | Deep Jungian theory, complexes, projection, shadow, individuation, dreams, active imagination, and post-Jungian development |
| **Lacanian Research Corpus** | Deep Lacanian theory, need/demand/desire, fantasy, jouissance, love, transference, partner-as-symptom, and clinical structure |

Version 2.0 of this corpus contains only concise bridge material to those specialist traditions.

## 5. Duplicate and low-priority source control

- `pesant-zadra-dreams-psychotherapy_2004.pdf` duplicates the Pesant and Zadra 2004 article. The canonical production copy is `1-s2.0-S0272735804000480-main.pdf`.
- The children's-dreams volume is retained as an archive/context source rather than reconstructed substantively.
- `Mind/Body Health` and `Sleep and Dreaming` are contextual sources, not structural anchors.
- The PRE-00 source audit is a production-control document and is intentionally not part of the final repository package.

## 6. Evidence-currency note

Version 2.0 is **source-grounded**, not continuously updated.

Important examples:

- the Project copy of *Attachment in Adulthood* is the 2007 edition;
- the Project copy of *Clinical Handbook of Couple Therapy* is the 2015 fifth edition;
- the Project copy of *The Cambridge Handbook of Personal Relationships* is the 2006 edition;
- Carr's evidence review is from 2018;
- the Acceptance and Commitment Therapy source is the 2012 second edition;
- Yalom's *Existential Psychotherapy* is the 1980 clinical-theoretical text;
- the most recent dedicated dream-science review in the source base is from 2022.

These sources remain valuable for the functions assigned to them, but the corpus should not describe itself as a live 2026 systematic review.

## 7. Routing by question

| Question | Start with | Then use |
|---|---|---|
| What is happening inside me? | File 01 | File 05, then File 06 |
| What is happening between us? | File 02 | File 06 |
| Which therapy model explains or treats this? | File 03 | File 06 |
| Is this a rupture, betrayal, attachment injury, incompatibility, or safety issue? | File 04 | File 06 |
| How should I reflect on an episode or dream? | File 05 | File 06 for integration |
| How do I analyse a concrete case using the whole corpus? | **File 06** | Files 01-05, 07 and 08 as domain references |
| I understand the pattern, but what do I choose or do? | File 07 | File 06 for integrated application |
| Is this a values conflict, acceptance question, or existential decision? | File 07 | Files 04 and 06 where boundaries, repair or safety matter |
| How might family-of-origin or multigenerational patterns matter? | File 08 | File 06 for integration; File 01 for attachment/agency distinctions |
| Is this differentiation, cutoff, a triangle, or an inherited family role? | File 08 | Files 02, 04 and 07 as needed |
| What does Jung specifically mean? | Jungian specialist corpus | Use this corpus only for applied bridge material |
| What does Lacan specifically mean? | Lacanian specialist corpus | Use this corpus only for applied bridge material |

## 8. Core source rule

When several sources can explain the same material:

1. start with the concrete event;
2. use the source appropriate to the question;
3. keep population-level evidence separate from case-level inference;
4. preserve disagreements among frameworks;
5. do not treat a more elaborate theory as more true merely because it is more elaborate;
6. use File 08 only when family evidence materially adds to the formulation;
7. use File 07 when the remaining task is values, choice, meaning, or committed action;
8. route the final integrated application through File 06.
